1. Get the application URL by running these commands:
{{- if .Values.ingress.enabled }}
{{- if and .Values.api.enabled .Values.api.ingress.enabled }}
{{- range $host := .Values.api.ingress.hosts }}
  {{- range .paths }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
  {{- end }}
{{- end }}
{{- end }}
{{- if and .Values.ui.enabled .Values.ui.ingress.enabled }}
{{- range $host := .Values.ui.ingress.hosts }}
  {{- range .paths }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
  {{- end }}
{{- end }}
{{- end }}
{{- else if contains "NodePort" .Values.api.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "ccf-app.fullname" . }}-api)
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "LoadBalancer" .Values.api.service.type }}
     NOTE: It may take a few minutes for the LoadBalancer IP to be available.
           You can watch its status by running 'kubectl get --namespace {{ .Release.Namespace }} svc -w {{ include "ccf-app.fullname" . }}-api'
  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "ccf-app.fullname" . }}-api --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo http://$SERVICE_IP:{{ .Values.api.service.port }}
{{- else if contains "ClusterIP" .Values.api.service.type }}
  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "ccf-app.name" . }},app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component={{ include "ccf-app.name" . }}-api" -o jsonpath="{.items[0].metadata.name}")
  export CONTAINER_PORT=$(kubectl get pod --namespace {{ .Release.Namespace }} $POD_NAME -o jsonpath="{.spec.containers[0].ports[0].containerPort}")
  echo "Visit http://127.0.0.1:{{ .Values.api.service.port }} to use your application"
  kubectl --namespace {{ .Release.Namespace }} port-forward $POD_NAME {{ .Values.api.service.port }}:$CONTAINER_PORT
{{- end }}

4. Next step: install an agent with the ccf-agent chart.
{{- if .Values.api.agentBootstrap.enabled }}
  The agent bootstrap Job writes agent keys to these Secrets (keys CCF_API_AUTH_CLIENT_ID and
  CCF_API_AUTH_CLIENT_SECRET), skipping Secrets that already exist:
{{- range (include "ccf-app.agentBootstrap.agents" . | fromJsonArray) }}
    - {{ .namespace }}/{{ .secretName }} (agent "{{ .name }}")
{{- end }}
{{- else }}
  Create an agent and a key in the UI under Admin -> Agents (or enable api.agentBootstrap),
  store the key in a Secret with the keys CCF_API_AUTH_CLIENT_ID and CCF_API_AUTH_CLIENT_SECRET,
{{- end }}
  then:
    helm install ccf-agent oci://ghcr.io/compliance-framework/helm-charts/ccf-agent \
      --set agent.api.url=http://{{ $fullname }}-api.{{ .Release.Namespace }}.svc:{{ .Values.api.service.port }} \
      --set agent.api.auth.enabled=true \
      --set agent.api.auth.existingSecret=<secret name>
{{- if not .Values.api.agents.strictDisablePublicEndpoints }}

NOTE: public agent endpoints are allowed (api.agents.strictDisablePublicEndpoints=false), so
anonymous callers can send evidence, upload artifacts and run Rego playback. Set it to true
once every agent has a key.
{{- end }}
{{- with (include "ccf-app.deprecatedGeneratedCredentials" .) }}

DEPRECATED: generated credentials ({{ . }}).
  These use the chart's pre-0.9.0 default: passwords come from lookup of the existing Secret,
  else a random value; the JWT signing key is a new random key on every render. This is not
  GitOps-safe: under Argo CD / helm template, lookup returns nothing, so the passwords are
  regenerated on every sync (the API can then no longer connect to an initialised PostgreSQL),
  and the JWT key rotates on every upgrade or sync (everyone is logged out, agent tokens stop
  working). This path will be removed in a future release. Migrate to existingSecret (the README
  copy recipe keeps the current values) or, for fresh installs only, externalSecret (External
  Secrets Operator). See the README, section Credentials.
{{- end }}
